<h1 align="left">🤖 LLM Tracker - by C0d3k</h1>

###

<p align="left">
🔍 Plugin avanzado para <b>WordPress</b> que detecta, rastrea y analiza visitas de <b>Language Learning Models (LLMs)</b> y bots en tu sitio web.<br><br>
📦 Versión: <b>1.0.0</b><br>
💻 WordPress: <b>5.0+</b> | PHP: <b>7.4+</b><br>
🧾 Licencia: <b>GPL v2</b>
</p>

###

<h2 align="left">📋 Características Principales</h2>

###

<p align="left">
✨ <b>Detección Inteligente</b>: Más de 100 tipos de bots (ChatGPT, Claude, Gemini, Googlebot, etc.)<br>
📊 <b>Panel de administración</b> con gráficos y estadísticas en tiempo real<br>
🛡️ <b>Seguridad</b>: Validación de datos, SQL Safe, y permisos de administrador<br>
🌍 <b>Geolocalización opcional</b> con APIs externas (ipstack, ipapi, etc.)<br>
📤 <b>Exportación CSV</b> y limpieza automática de base de datos
</p>

###

<h2 align="left">⚙️ Instalación</h2>

###

<p align="left">
📥 <b>Automática:</b> Desde el panel de WordPress → Plugins → Añadir nuevo → “LLM Tracker - by C0d3k”<br>
📦 <b>Manual:</b> Sube la carpeta <code>llm-tracker-for-wordpress</code> a <code>/wp-content/plugins/</code> y actívalo.
</p>

###

<h2 align="left">🧭 Uso del Plugin</h2>

###

<p align="left">
📊 <b>Dashboard:</b> Estadísticas y gráficos<br>
📅 <b>Filtros:</b> Por fecha, tipo (bot/humano) e IP<br>
📈 <b>Métricas:</b> Visitas totales, bots detectados, IPs únicas, tendencias<br>
📤 <b>Exportar:</b> Genera informes CSV filtrados
</p>

###

<h2 align="left">🎯 Tipos de Bots Detectados</h2>

###

<p align="left">
🤖 <b>LLMs:</b> ChatGPT, Claude, Gemini, LLaMA<br>
🌐 <b>Crawlers:</b> Googlebot, Bingbot, DuckDuckBot, Baidu<br>
💬 <b>Social Media:</b> Facebook, Twitter/X, LinkedIn, WhatsApp
</p>
